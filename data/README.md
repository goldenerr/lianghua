# 数据目录版本管理说明

本目录中的行情、资金流、日内数据、财务数据、分析师数据、归档快照和派生特征均属于可再生成或可从外部数据源恢复的大型数据资产，不纳入 Git 版本历史。

Git 仅保存以下内容：

- 小型股票池、数据清单和来源说明；
- 数据版本、哈希及质量门禁结果；
- 紧凑的回测结果与生产准入证据；
- 获取、校验、归档和恢复数据的脚本。

大型数据应保存在本地数据盘、受控对象存储或具备版本管理能力的数据仓中。生产环境应同时保存不可篡改的清单、对象哈希、来源授权和归档证明，不能用 Git 提交代替 WORM 或数据供应商证据。

被 `.gitignore` 排除的数据文件仍会保留在本地，不会因取消 Git 跟踪而删除。重新克隆仓库后，应使用 `scripts/` 下对应的数据获取或恢复脚本重建这些目录。
